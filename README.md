# Website UMKM Juragan Donat

🍩 Juragan Donat – Website UMKM
Juragan Donat adalah website yang dibuat untuk pembelajaran dalam mata kuliah pemrograman web dan juga karena saya suka donat apalagi donat coklat.

📌 Fitur Website
Website Juragan Donat memiliki beberapa fitur utama, antara lain:
🔹 Halaman Beranda
Menampilkan gambaran umum usaha Juragan Donat.
🔹 Tentang Kami
Informasi profil usaha, sejarah singkat, dan produk unggulan.
🔹 Halaman Produk
Menampilkan daftar produk donat beserta harga.
🔹 Galeri Foto
Menampilkan dokumentasi toko, proses produksi, dan produk.
🔹 Keranjang Belanja Sederhana
Menampilkan item yang dipilih
Menghitung total harga otomatis
Tombol pesan dengan notifikasi berhasil menggunakan jQuery
🔹 Halaman Kontak
Form kontak interaktif
Validasi input menggunakan jQuery
Alert notifikasi ketika form berhasil dikirim
🔹 Responsive Design
Tampilan menyesuaikan perangkat (desktop & mobile) dengan Bootstrap 5.

🛠️ Teknologi yang Digunakan
HTML5 – Struktur halaman website
CSS – Styling tambahan
Bootstrap 5 – Framework UI & responsive layout
JavaScript – Logika interaksi
jQuery – Validasi form & manipulasi DOM

📄 Lisensi
Project ini dibuat untuk keperluan pembelajaran dan non-komersial.
